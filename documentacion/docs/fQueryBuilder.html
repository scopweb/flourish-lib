The Query Builder provides a modern, fluent interface for building database queries while maintaining full backward compatibility with existing Flourish applications. It offers better developer experience, automatic SQL injection protection, and database-agnostic query generation.

Introduction

Flourish's Query Builder brings Laravel/Eloquent-style fluent interfaces to database operations while preserving Flourish's security-first approach and compatibility with multiple database systems.

Key Benefits:

  • Better DX: Method chaining and intuitive API
  • SQL Injection Protection: Automatic parameter binding
  • Database Agnostic: Works with MySQL, PostgreSQL, SQLite
  • 100% Backward Compatible: Existing code continues to work

Quick Start

Basic Setup

table('users')->where('active', '=', 1)->get();
// OR
$users = fDB::table('users')->where('active', '=', 1)->get();
?>

Basic Queries

SELECT Queries

table('users')->get();

// SELECT specific columns
$users = $db->table('users')
            ->select(['id', 'name', 'email'])
            ->get();

// SELECT with WHERE clause
$activeUsers = $db->table('users')
                  ->where('active', '=', 1)
                  ->get();

// Multiple WHERE conditions
$users = $db->table('users')
            ->where('active', '=', 1)
            ->where('age', '>', 18)
            ->get();

// WHERE with OR
$users = $db->table('users')
            ->where('active', '=', 1)
            ->orWhere('admin', '=', 1)
            ->get();

// Get first result only
$user = $db->table('users')
           ->where('email', '=', 'john@example.com')
           ->first();
?>

INSERT Queries

table('users')->insert([
    'name' => 'John Doe',
    'email' => 'john@example.com',
    'age' => 30
]);

// Using static facade
fDB::insertInto('users', [
    'name' => 'Jane Smith',
    'email' => 'jane@example.com',
    'age' => 25
]);
?>

UPDATE Queries

table('users')
   ->where('id', '=', 1)
   ->update([
       'name' => 'John Smith',
       'email' => 'johnsmith@example.com'
   ]);

// Using static facade
fDB::updateTable('users', ['active' => 0])
   ->where('last_login', '<', '2023-01-01')
   ->execute();
?>

DELETE Queries

table('users')
   ->where('active', '=', 0)
   ->delete();

// Using static facade
fDB::deleteFrom('users')
   ->where('created_at', '<', '2020-01-01')
   ->execute();
?>

Advanced WHERE Clauses

whereIn / whereNotIn

table('users')
            ->whereIn('id', [1, 2, 3, 4, 5])
            ->get();

$users = $db->table('users')
            ->whereNotIn('status', ['banned', 'suspended'])
            ->get();
?>

whereNull / whereNotNull

table('users')
            ->whereNull('deleted_at')
            ->get();

$profiles = $db->table('profiles')
               ->whereNotNull('bio')
               ->get();
?>

whereBetween

table('products')
               ->whereBetween('price', 10, 100)
               ->get();
?>

whereLike

table('users')
            ->whereLike('name', '%John%')
            ->get();
?>

whereExists / whereNotExists

table('users')
            ->whereExists(function($query) {
                $query->table('orders')
                      ->whereRaw('orders.user_id = users.id');
            })
            ->get();

// Users who have no orders
$users = $db->table('users')
            ->whereNotExists(function($query) {
                $query->table('orders')
                      ->whereRaw('orders.user_id = users.id');
            })
            ->get();
?>

Raw WHERE clauses

table('users')
            ->whereRaw('YEAR(created_at) = YEAR(NOW())')
            ->get();
?>

JOIN Operations

Basic JOINs

table('users')
            ->join('profiles', 'users.id', '=', 'profiles.user_id')
            ->select(['users.name', 'profiles.bio'])
            ->get();

// LEFT JOIN
$users = $db->table('users')
            ->leftJoin('orders', 'users.id', '=', 'orders.user_id')
            ->select(['users.name', 'COUNT(orders.id) as order_count'])
            ->groupBy('users.id')
            ->get();

// RIGHT JOIN
$orders = $db->table('orders')
             ->rightJoin('users', 'orders.user_id', '=', 'users.id')
             ->get();

// CROSS JOIN
$combinations = $db->table('colors')
                   ->crossJoin('sizes')
                   ->get();
?>

Multiple JOINs

table('users')
           ->join('profiles', 'users.id', '=', 'profiles.user_id')
           ->leftJoin('orders', 'users.id', '=', 'orders.user_id')
           ->leftJoin('order_items', 'orders.id', '=', 'order_items.order_id')
           ->select([
               'users.name',
               'profiles.bio',
               'COUNT(DISTINCT orders.id) as order_count',
               'COUNT(order_items.id) as item_count'
           ])
           ->groupBy('users.id')
           ->get();
?>

Raw SQL Expressions

Using Raw Expressions

table('users')
            ->select([
                $db->raw('COUNT(*) as total_users'),
                $db->raw('AVG(age) as average_age'),
                $db->raw('MAX(created_at) as latest_registration')
            ])
            ->first();

// Using static facade
$stats = fDB::table('orders')
            ->select([
                fDB::raw('DATE(created_at) as order_date'),
                fDB::raw('COUNT(*) as daily_orders'),
                fDB::raw('SUM(total) as daily_revenue')
            ])
            ->groupBy(fDB::raw('DATE(created_at)'))
            ->get();
?>

Security & SQL Injection Protection

The Query Builder automatically protects against SQL injection by using parameter binding:

table('users')
            ->where('email', '=', $_POST['email'])  // Automatically escaped
            ->get();

// The malicious input is safely handled:
$maliciousInput = "'; DROP TABLE users; --";
$users = $db->table('users')
            ->where('name', '=', $maliciousInput)  // Becomes parameter binding
            ->get();
// Generated SQL: SELECT * FROM users WHERE name = %s
// Binding: ["'; DROP TABLE users; --"]

// For raw SQL, use fRawExpression when you need unescaped SQL
$users = $db->table('users')
            ->whereRaw('created_at > NOW() - INTERVAL 1 DAY')
            ->get();
?>

Backward Compatibility

The Query Builder maintains 100% backward compatibility with existing Flourish code:

query("SELECT * FROM users WHERE active = %i", 1);

// New way (enhanced DX)
$result = $db->table('users')->where('active', '=', 1)->get();

// Both approaches can be mixed in the same application
$oldStyleResult = $db->query("SELECT COUNT(*) as count FROM users");
$newStyleUsers = $db->table('users')
                    ->where('created_at', '>', '2024-01-01')
                    ->orderBy('name')
                    ->get();
?>

?>
