PHP Version Requirements

This modified version requires PHP 8.4.0 or greater. All 64 classes have been updated with modern PHP patterns including variadic parameters, updated boolean constants, and enhanced type handling.

Core extensions required by all Flourish classes:

  • ctype
  • iconv
  • pcre
  • session
  • spl

It is possible to disable these extensions when compiling PHP, so you will need to ensure each is installed. The simplest way is to look at the output of a script with the following contents: 

<?php
phpinfo();

Database Extensions

fDatabase and related classes now require modern database extensions:

Database Type Required Extension Status
MySQL/MariaDB mysqli (preferred) or pdo_mysql ✅ Fully tested and compatible
PostgreSQL pdo_pgsql ✅ Compatible (not extensively tested)
SQLite pdo_sqlite ✅ Compatible (not extensively tested)
MSSQL pdo_sqlsrv ⚠️ Should work (untested)
Oracle pdo_oci ⚠️ Should work (untested)

⚠️ Important: The legacy mysql extension (removed in PHP 7.0) is no longer supported. Classes fStatement and fUnbufferedResult have been completely rewritten for modern extensions.

Class Specific Requirements

Beyond the core requirements, some classes require additional extensions for specific functionality:

Classes/Methods Extensions Required
fCrytography::publicKeyEncrypt(), fCryptography::publicKeyDecrypt() openssl
fCrytography::publicKeySign(), fCryptography::publicKeyVerify() openssl
fCryptography::symmetricKeyEncrypt(), fCryptography::symmetricKeyDecrypt() openssl (mcrypt deprecated since PHP 7.1)
fEmail::sign(), fEmail::encrypt() openssl
fSMTP::__construct() with the $secure flag openssl
