📚 Descripción

La clase fRedis proporciona una interfaz completa para trabajar con Redis, incluyendo cache moderno, almacenamiento de sesiones, y estructuras de datos avanzadas. Extiende fDatabase para mantener consistencia con el ecosistema Flourish.

🚀 Características Principales:
  • Operaciones de strings, listas, hashes, sets y pub/sub
  • Múltiples métodos de serialización (PHP, JSON, igbinary, msgpack)
  • Integración completa con fSession
  • Soporte para TTL y operaciones atómicas
  • Manejo robusto de errores y reconexión automática

set() / get()

// Operaciones básicas

// Con TTL

// Múltiples operaciones

    'user:1001' => 'John Doe',

    'user:1003' => 'Bob Johnson'

💾 Casos de Uso de Caching

// Cache de datos de usuario
function getUserProfile($userId) {
    global $redis, $database;
    
    $cacheKey = "user:profile:{$userId}";
    
    // Intentar obtener del cache
    $profile = $redis->get($cacheKey);
    if ($profile !== null) {
        return $profile;
    }
    
    // No en cache, obtener de la base de datos
    $profile = $database->query("SELECT * FROM users WHERE id = %i", $userId)->fetch();
    
    // Guardar en cache por 1 hora
    $redis->set($cacheKey, $profile, 3600);
    
    return $profile;
}

// Cache de resultados de consultas costosas
function getPopularProducts() {
    global $redis, $database;
    
    $cacheKey = 'products:popular';
    
    $products = $redis->get($cacheKey);
    if ($products !== null) {
        return $products;
    }
    
    // Consulta costosa
    $products = $database->query("
        SELECT p.*, COUNT(o.id) as order_count 
        FROM products p 
        JOIN order_items o ON p.id = o.product_id 
        GROUP BY p.id 
        ORDER BY order_count DESC 
        LIMIT 10
    ")->fetchAll();
    
    // Cache por 30 minutos
    $redis->set($cacheKey, $products, 1800);
    
    return $products;
}

⚡ Performance y Best Practices

🎯 Recomendaciones

  • Pipeline operations: Usa setMultiple/getMultiple para operaciones en lote
  • TTL apropiados: Establece TTL para evitar memory leaks
  • Claves descriptivas: Usa prefijos como 'user:', 'session:', 'cache:'
  • Serialización: JSON para compatibilidad, igbinary para performance
  • Monitoreo: Usa getInfo() para monitorear el estado del servidor
  • Cleanup: Implementa limpieza de claves obsoletas
// Ejemplo de limpieza automática
function cleanupOldSessions() {
    global $redis;
    
    $sessionKeys = $redis->keys('sessions:*');
    foreach ($sessionKeys as $key) {
        $ttl = $redis->ttl($key);
        if ($ttl <= 0) { // Clave sin TTL o expirada
            $redis->delete($key);
        }
    }
}
