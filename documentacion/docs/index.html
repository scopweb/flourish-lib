📚 PHP 8.4 Compatible Documentation

All 64 classes documented below are fully compatible with PHP 8.4 and have been modernized with variadic parameters, boolean constants, and modern database extensions.

New PHP 8.4 Features: Modern enums for type safety (JsonToken, DatabaseType, MimeType, MongoDbType), asymmetric visibility for better encapsulation, property hooks for cleaner APIs, deprecated method attributes for IDE support, and comprehensive migration guidance.

✨ Modern APIs (FASE 4): Native PHP 8.4 array functions (array_find, array_any, array_all, array_find_key), BcMath\Number precision arithmetic in fMoney, and enhanced string functions (str_contains, str_starts_with, str_ends_with) for better performance and cleaner code.

🚀 NEW PHP 8.4 Classes: fRedis - Modern Redis cache & session storage with pub/sub support. fHttpClient - PSR-18 compatible HTTP client with property hooks, middleware, and modern authentication. Both classes include comprehensive test suites and production-ready implementations.
