📚 Descripción

La clase fContainer proporciona un moderno sistema de Dependency Injection compatible con PSR-11, incluyendo autowiring automático, singleton management, interface binding, y soporte completo para attributes de PHP 8.4.

🚀 Características Principales:
  • Container PSR-11 compatible con autowiring automático
  • Singleton management con #[Singleton] attribute
  • Interface binding con factory functions
  • Asymmetric visibility para debugging (PHP 8.4)
  • Reflection caching para performance optimizada
  • Method chaining para configuración fluida
  • Helper functions globales para acceso conveniente

// Service that uses repository
class UserService
{
    public function __construct(
        private UserRepositoryInterface $userRepository,
        private LoggerInterface $logger
    ) {}
    
    public function createUser(array $userData): User
    {
        $user = new User($userData);
        
        if ($this->userRepository->save($user)) {
            $this->logger->log("User created: " . $user->getId());
            return $user;
        }
        
        throw new Exception("Failed to create user");
    }
}

singleton(fDatabase::class, function($container) {
            $config = $container->resolve('config');

            }
            return new fCache();
        });
    }
    
    public function boot(fContainer $container): void
    {
        // Boot logic - runs after all providers are registered
        $database = $container->resolve(fDatabase::class);
        $database->enableDebugging();
    }
}

🚨 Error Handling

$container = fContainer::getInstance();

try {
    // Service que no existe
    $service = $container->resolve('non.existent.service');
} catch (fProgrammerException $e) {
    echo "Service not found: " . $e->getMessage();
}

try {
    // Circular dependency o parámetros faltantes
    $service = $container->resolve(ComplexService::class);
} catch (fProgrammerException $e) {
    echo "Cannot resolve dependencies: " . $e->getMessage();
}

// Check if service exists
if ($container->has('optional.service')) {
    $service = $container->resolve('optional.service');

    $service = new DefaultService();

⚡ Performance y Best Practices

🎯 Recomendaciones

  • Singleton heavy services: Usa singleton para database, cache, config
  • Factory for stateful: Usa factories para objects con estado
  • Interface binding: Siempre bind interfaces, no implementaciones
  • Lazy loading: Usa factories para expensive objects
  • Reflection cache: Container cachea reflection automáticamente
  • Service providers: Organiza bindings en service providers
  • Environment specific: Usa factories para configuración por environment
// ✅ Good practices
$container->singleton(fDatabase::class, function() {
    // Expensive to create, reuse instance
    return new fDatabase(...);
});

$container->bind(LoggerInterface::class, function($container) {
    $config = $container->resolve('config');
    return $config->get('debug') 
        ? new VerboseLogger() 
        : new SilentLogger();
});

// ❌ Avoid
$container->bind('logger', 'FileLogger'); // Bind to concrete class
$container->instance('database', new fDatabase(...)); // Creates immediately
