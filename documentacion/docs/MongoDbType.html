The MongoDbType enum provides type safety for MongoDB BSON (Binary JSON) data types, offering validation, conversion, and utility methods for working with MongoDB documents in a type-safe manner.

Introduction

MongoDB stores data in BSON format, which supports more data types than JSON. The MongoDbType enum brings PHP 8.4's type safety features to MongoDB operations, making it easier to work with different BSON data types correctly.

BSON Types

The enum supports all major BSON data types:

Scalar Types

  • Double - 64-bit floating point numbers
  • String - UTF-8 strings
  • Boolean - true/false values
  • Int32 - 32-bit integers
  • Int64 - 64-bit integers

Special Types

  • ObjectId - 12-byte unique identifiers
  • Date - UTC datetime (milliseconds since epoch)
  • Timestamp - MongoDB internal timestamp
  • Null - Null values

Structural Types

  • Object - Embedded documents
  • Array - Ordered lists
  • Binary - Binary data

Advanced Types

  • Regex - Regular expressions
  • JavaScript - JavaScript code
  • Decimal128 - High-precision decimals

Type Conversion

Convert between PHP values and BSON objects:

convertFromPhp('507f1f77bcf86cd799439011');
// Returns: MongoDB\BSON\ObjectId instance

$date = MongoDbType::Date->convertFromPhp(time());
// Returns: MongoDB\BSON\UTCDateTime instance

$decimal = MongoDbType::Decimal128->convertFromPhp('123.456');
// Returns: MongoDB\BSON\Decimal128 instance

// Convert BSON objects to PHP values
$phpValue = MongoDbType::String->convertToPhp(new MongoDB\BSON\ObjectId());
// Returns: string representation of ObjectId

// Validate before conversion
if (MongoDbType::Date->canConvertFromPhp($timestamp)) {
    $bsonDate = MongoDbType::Date->convertFromPhp($timestamp);
}
?>

Type-Safe Query Building

filters[] = [
            'field' => $field,
            'operator' => '$eq',
            'value' => $value,
            'type' => $type
        ];
        
        return $this;
    }
    
    public function whereIn(string $field, array $values): self {
        // Validate all values have the same type
        $types = array_map([MongoDbType::class, 'detectFromPhpValue'], $values);
        $uniqueTypes = array_unique($types);
        
        if (count($uniqueTypes) > 1) {
            throw new InvalidArgumentException("All values in whereIn must have the same type");
        }
        
        $this->filters[] = [
            'field' => $field,
            'operator' => '$in',
            'value' => $values,
            'type' => $types[0]
        ];
        
        return $this;
    }
    
    public function build(): array {
        $query = [];
        
        foreach ($this->filters as $filter) {
            $query[$filter['field']] = [
                $filter['operator'] => $filter['value']
            ];
        }
        
        return $query;
    }
}

// Usage
$query = (new TypeSafeQuery())
    ->whereEquals('status', 'active')
    ->whereIn('department', ['Engineering', 'Design'])
    ->build();
?>
