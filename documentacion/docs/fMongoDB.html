The fMongoDB class provides modern NoSQL database support for MongoDB, following Flourish patterns while offering MongoDB-specific functionality like document operations, aggregation pipelines, and flexible schema handling.

Introduction

MongoDB is a popular NoSQL document database that stores data in flexible, JSON-like documents. The fMongoDB class brings MongoDB support to Flourish applications while maintaining the framework's signature simplicity and security focus.

Requirements

To use fMongoDB, you need:

  • PHP 8.4+ with MongoDB extension installed
  • MongoDB Server 4.2+
  • MongoDB PHP Driver 1.20+

Install the MongoDB PHP extension:

pecl install mongodb

# Add to php.ini
extension=mongodb

Document Operations

Inserting Documents

Insert single or multiple documents:

selectCollection('users');

// Insert single document
$result = $users->insertOne([
    'name' => 'John Doe',
    'email' => 'john@example.com',
    'profile' => [
        'age' => 30,
        'department' => 'Engineering'
    ],
    'tags' => ['developer', 'php'],
    'created_at' => new MongoDB\BSON\UTCDateTime()
]);

echo "Inserted ID: " . $result->getInsertedId();

// Insert multiple documents
$result = $users->insertMany([
    ['name' => 'Alice', 'email' => 'alice@example.com'],
    ['name' => 'Bob', 'email' => 'bob@example.com']
]);

echo "Inserted " . $result->getInsertedCount() . " documents";
?>

Querying Documents

Find documents with various query patterns:

findOne(['email' => 'john@example.com']);

// Find multiple documents
$engineers = $users->find(['profile.department' => 'Engineering']);

foreach ($engineers as $engineer) {
    echo $engineer['name'] . " - " . $engineer['email'] . "\n";
}

// Advanced queries
$activeUsers = $users->find([
    'status' => 'active',
    'profile.age' => ['$gte' => 18, '$lte' => 65],
    'tags' => ['$in' => ['developer', 'designer']]
]);

// Query with options
$recentUsers = $users->find(
    ['created_at' => ['$gte' => new MongoDB\BSON\UTCDateTime(strtotime('-7 days') * 1000)]],
    [
        'sort' => ['created_at' => -1],
        'limit' => 10,
        'projection' => ['name' => 1, 'email' => 1]
    ]
);
?>

Updating Documents

Update existing documents:

updateOne(
    ['email' => 'john@example.com'],
    [
        '$set' => [
            'profile.age' => 31,
            'updated_at' => new MongoDB\BSON\UTCDateTime()
        ],
        '$addToSet' => ['tags' => 'senior']
    ]
);

echo "Modified " . $result->getModifiedCount() . " document";

// Update multiple documents
$result = $users->updateMany(
    ['profile.department' => 'Engineering'],
    ['$set' => ['profile.team' => 'Backend']]
);

// Upsert (insert if not exists)
$result = $users->updateOne(
    ['email' => 'new@example.com'],
    ['$set' => ['name' => 'New User']],
    ['upsert' => true]
);
?>

Deleting Documents

Delete documents:

deleteOne(['email' => 'old@example.com']);
echo "Deleted " . $result->getDeletedCount() . " document";

// Delete multiple documents
$result = $users->deleteMany([
    'status' => 'inactive',
    'last_login' => ['$lt' => new MongoDB\BSON\UTCDateTime(strtotime('-1 year') * 1000)]

?>

Aggregation Pipelines

Use MongoDB's powerful aggregation framework:

aggregate([
    ['$match' => ['status' => 'active']],
    ['$group' => [
        '_id' => '$profile.department',
        'count' => ['$sum' => 1],
        'avgAge' => ['$avg' => '$profile.age']
    ]],
    ['$sort' => ['count' => -1]]
]);

foreach ($stats as $stat) {
    echo "Department: " . $stat['_id'] . "\n";
    echo "Count: " . $stat['count'] . "\n";
    echo "Average Age: " . round($stat['avgAge'], 1) . "\n\n";
}

// Complex multi-stage pipeline
$pipeline = [
    ['$match' => ['status' => 'active']],
    ['$addFields' => [
        'fullName' => ['$concat' => ['$firstName', ' ', '$lastName']]
    ]],
    ['$group' => [
        '_id' => '$profile.department',
        'users' => ['$push' => [
            'name' => '$fullName',
            'email' => '$email'
        ]]
    ]]
];

$departmentUsers = $users->aggregate($pipeline);
?>

Index Management

Create and manage indexes for better performance:

createIndex(['email' => 1], ['unique' => true]);
$users->createIndex(['profile.department' => 1, 'status' => 1]);

// Text search index
$users->createIndex(['name' => 'text', 'profile.bio' => 'text']);

// TTL index (auto-expire documents)
$sessions = $mongodb->selectCollection('sessions');
$sessions->createIndex(['createdAt' => 1], ['expireAfterSeconds' => 3600]);

// List indexes
$indexes = $users->listIndexes();
foreach ($indexes as $index) {
    echo "Index: " . $index['name'] . "\n";
}
?>
