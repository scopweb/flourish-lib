Array Functions PHP 8.4

Native PHP 8.4 array functions provide superior performance and cleaner code for array processing operations throughout the framework.

New Functions Implemented

// Find first element matching predicate
$result = array_find($numbers, fn($n) => $n > 10);

// Find first key where predicate matches  
$key = array_find_key($assoc, fn($value, $key) => $value > 100);

// Check if any element matches predicate
$hasValid = array_any($values, fn($v) => !empty($v));

// Check if all elements match predicate
$allValid = array_all($numbers, fn($n) => $n > 0);

  • fValidation - hasValue() and rule checking methods optimized with array_any()
  • fCore - New extension detection methods using array functions

BcMath\Number Integration

Enhanced monetary calculations with arbitrary precision arithmetic using PHP 8.4's native BcMath\Number class.

fMoney Enhancements

// Native BcMath\Number support
$precise = new BcMath\Number('123.456789');
$money = new fMoney($precise, 'USD');

// Enhanced arithmetic with automatic precision
$sum = $money1->add($money2);     // Uses BcMath\Number precision
$diff = $money1->sub($money2);    // Precise subtraction
$product = $money->mul('2.5');    // Automatic type conversion

// Precise currency conversion
$euros = $usd->convert('EUR');    // BcMath\Number precision

Key Benefits

  • Arbitrary Precision: No floating-point precision issues
  • Automatic Optimization: Uses BcMath\Number when available, fallback to fNumber
  • Type Safety: Runtime validation and conversion
  • 100% Compatible: Existing code works unchanged
